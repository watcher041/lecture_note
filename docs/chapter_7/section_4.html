相対論的電磁気学

電磁気学においては、Maxwell方程式と呼ばれるものを用いてあらゆる現象を説明することができた。具体的に、ある系 K においては以下のように表される。

∇⋅D=ρ、∇⋅B=0、∇×E=−∂t∂B​、∇×H=i+∂t∂D​

ここで、E は電場、B は磁束密度、D は電束密度、H は磁場（磁界の強さ）、ρ は電荷密度、i は電流密度である。真空になると D=ϵ0​E、B=μ0​H となる。ここで ϵ0​ は真空の誘電率、μ0​ は真空の透磁率である。ここまでのことをふまえて、まず K' 系においてのMaxwell方程式を

∇′⋅D′=ρ′、∇′⋅B′=0、∇′×E′=−∂t′∂B′​、∇′×H′=i′+∂t′∂D′​

と相対性原理をもとに表せたとする。このうち、２番目と３番目の式は

∂x′∂Bx′​​+∂y′∂By′​​+∂z′∂Bz′​​=0 ∂y′∂Ez′​​−∂z′∂Ey′​​=−∂t′∂Bx′​​、∂z′∂Ex′​​−∂x′∂Ez′​​=−∂t′∂By′​​、∂x′∂Ey′​​−∂y′∂Ex′​​=−∂t′∂Bz′​​

と各成分ごとに書き下せるが、ここでLotrentz変換

x′=γ(x−βw)、y′=y、z′=z、w′=γ(w−βx)、(β=cV​、γ=1−β2​1​)

から逆変換を求めると

x=γ(x′+βw′)、y=y′、z=z′、w=γ(w′+βx′)

となることから、各偏微分は以下の通り変換される。

∂x′∂​=∂x′∂x​∂x∂​+∂x′∂w​∂w∂​=γ∂x∂​+γc2V​∂t∂​ ∂y′∂​=∂y′∂y​∂y∂​=∂y∂​ ∂z′∂​=∂z′∂z​∂z∂​=∂z∂​ ∂t′∂​=∂t′∂w′​∂w′∂​=c(∂w′∂x​∂x∂​+∂w′∂w​∂w∂​)=γV∂x∂​+γ∂t∂​

となるため、これらを適用すると以下の形が得られる。

γ∂x∂Bx′​​+γc2V​∂t∂Bx′​​+∂y∂By′​​+∂z∂Bz′​​=0 ∂y∂Ez′​​−∂z∂Ey′​​=−γV∂x∂Bx′​​−γ∂t∂Bx′​​ ∂z∂Ex′​​−γ∂x∂Ez′​​−γc2V​∂t∂Ez′​​=−γV∂x∂By′​​−γ∂t∂By′​​ γ∂x∂Ey′​​+γc2V​∂t∂Ey′​​−∂y∂Ex′​​=−γV∂x∂Bz′​​−γ∂t∂Bz′​​

このうち、２番目の式を

γ∂t∂Bx′​​=−γV∂x∂Bx′​​−∂y∂Ez′​​+∂z∂Ey′​​

と置き換えて１番目の式に代入すると以下の式が得られる。

∂x∂Bx′​​+∂y∂​γ(By′​−c2V​Ez′​)+∂z∂​γ(Bz′​+c2V​Ey′​)=0

一方で、今度は１番目の式を

γ∂x∂Bx′​​=−γc2V​∂t∂Bx′​​−∂y∂By′​​−∂z∂Bz′​​

として二番目の式に代入すると以下の式が得られる。

∂y∂​γ(Ez′​−VBy′​)−∂z∂​γ(Ey′​+VBz′​)=−∂t∂Bx′​​

残りの３，４番目の式も整理することで以下の通りとなる。

∂z∂Ex′​​−γ∂x∂​(Ez′​−VBy′​)=−γ∂t∂​(By′​−c2V​Ez′​) ∂x∂​γ(Ey′​+VBz′​)−∂y∂Ex′​​=−γ∂t∂​(Bz′​+c2V​Ey′​)

ここまでの式をまとめると、以下の通りとなる。

∂x∂Bx′​​+∂y∂​γ(By′​−c2V​Ez′​)+∂z∂​γ(Bz′​+c2V​Ey′​)=0 ∂y∂​γ(Ez′​−VBy′​)−∂z∂​γ(Ey′​+VBz′​)=−∂t∂Bx′​​ ∂z∂Ex′​​−γ∂x∂​(Ez′​−VBy′​)=−γ∂t∂​(By′​−c2V​Ez′​) ∂x∂​γ(Ey′​+VBz′​)−∂y∂Ex′​​=−γ∂t∂​(Bz′​+c2V​Ey′​)

これらの式から、以下の関係式が成り立つことが予想される。

Ex​=Ex′​、Ey​=γ(Ey′​+VBz′​)、Ez​=γ(Ez′​−VBy′​) Bx​=Bx′​、By​=γ(By′​−c2V​Ez′​)、Bz​=γ(Bz′​+c2V​Ey′​)

確認のため、これらの逆変換を求めるとこちらも符号が反転しているだけで対照的な形となっている。

Ex′​=Ex​、Ey′​=γ(Ey​−VBz​)、Ez′​=γ(Ez​+VBy​) Bx′​=Bx​、By′​=γ(By​+c2V​Ez​)、Bz′​=γ(Bz​−c2V​Ey​)

ここで、さらに真空中であることを考慮する（光速が真空中での速度であるため）と光速が

c=ϵ0​μ0​​1​

であるから、上記の変換式は　

D′=ϵ0​E′、B′=μ0​H′、D=ϵ0​E、B=μ0​H

の関係式から以下の通りとなる。

Dx′​=Dx​、Dy′​=γ(Dy​−c2V​Hz​)、Dz′​=γ(Dz​+c2V​Hy​) Hx′​=Hx​、Hy′​=γ(Hy​+VDz​)、Hz′​=γ(Hz​−VDy​)

これらの式を用いると、Maxwell方程式の１番目の式と4番目の式が

∂x′∂Dx′​​+∂y′∂Dy′​​+∂z′∂Dz′​​=ρ′

∂y′∂Hz′​​−∂z′∂Hy′​​=ix′​+∂t′∂Dx′​​、∂z′∂Hx′​​−∂x′∂Hz′​​=iy′​+∂t′∂Dy′​​、∂x′∂Hy′​​−∂y′∂Hx′​​=iz′​+∂t′∂Dz′​​

となるため、電荷密度と電流は以下の通りとなる。

ρ′=γ(∂x∂Dx​​+∂y∂Dy​​+∂z∂Dz​​)+γc2V​[∂t∂Dx​​−(∂y∂Hz​​−∂z∂Hy​​)]=γ(ρ−c2V​ix​) ix′​=γ[(∂y∂Hz​​−∂z∂Hy​​)−∂t∂Dx​​]−γV(∂x∂Dx​​+∂y∂Dy​​+∂z∂Dz​​)=γ(ix​−Vρ) iy′​=(∂z∂Hx​​−∂x∂Hz​​)−∂t∂Dy​​=iy​ iz′​=(∂x∂Hy​​−∂y∂Hx​​)−∂t∂Dz​​=iz​

媒質中の場合（補足）

ここまでは真空中で考えてきたが、水やガラスのような媒質の中ではどうなるだろうか。

まず光の速さについて、媒質中では屈折率 n を用いて c/n となる。これは媒質が静止している系での値であり、Lorentz変換に現れる c とは別のものである。実際、媒質が静止している系では誘電率 ϵ、透磁率 μ を用いて D=ϵE、B=μH となるため、電磁波の速さは 1/ϵμ​=c/n となる。c はどの慣性系でも同じ値をとる速さの上限であるのに対し、c/n は媒質の静止系で決まる値である。

次に変換則について、前に求めた E,B の変換則は ∇⋅B=0 と ∇×E=−∂B/∂t のみから導いたため、媒質があっても変わらない。同様に、自由電荷・自由電流に対する ∇⋅D=ρ と ∇×H=i+∂D/∂t からは

Dx​=Dx′​、Dy​=γ(Dy′​+c2V​Hz′​)、Dz​=γ(Dz′​−c2V​Hy′​) Hx​=Hx′​、Hy​=γ(Hy′​−VDz′​)、Hz​=γ(Hz′​+VDy′​)

が得られ、これも媒質があっても同じ形になる。変わるのは D と E、B と H の関係であり、D=ϵE、B=μH は媒質が静止している系でのみ成り立つ。媒質が速度 v で動いて見える系では、

D+c2v×H​=ϵ(E+v×B)、B−c2v×E​=μ(H−v×D)

という関係に置き換わる。

最後に、動いている媒質の中での光の速さを考える。K' 系で媒質が静止していて、光が x 方向に速さ c/n で進むとすると、K 系での光の速さ u は、速度の変換式の逆変換から

u=1+V/(nc)c/n+V​≃nc​+V(1−n21​)

となる（V≪c の最低次まで）。媒質の速さ V に対して 1−1/n2 だけ引きずられることになり、これはFresnelの引きずり係数と呼ばれ、Fizeauの流水の実験で確かめられている。なお n>1、V<c のとき u<c である。

また、媒質中では荷電粒子が c/n より速く進むことができ（Cherenkov放射）、このとき c は超えない。以上のように、媒質中の光が遅いことは、光速度不変の原理や相対性原理と矛盾しない。
